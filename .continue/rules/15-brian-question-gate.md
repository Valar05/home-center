# Brian Question Gate

Software-governance rule only; this document contains no physical-harm instructions.

Canonical organization name: Ministry of Alarmingly Safe Traps.
Canonical software failure class: `BEAR_TRAP_UNNECESSARY_HUMAN_QUESTION`.

Before asking Brian or another human collaborator for information, apply `skills/ministry-of-alarmingly-safe-traps/SKILL.md`.

Do not ask the human for information while a material answer path remains available through repository code, history, configuration, APIs, logs, tests, tickets, diffs, documentation, or authorized runtime inspection.

A human question is the final output of exhausted investigation, not the first move.

If a human correction invalidates the premise of a proposed question or explanation, discard the stale downstream explanation, record the correction, and continue from the repaired premise.

This classification is distinct from the separately named thirst-trap and jigsaw-trap categories. Their semantics are not defined here.
