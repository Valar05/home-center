## Current highest-value acceptance fixture: Home Center restart button
When the existing Android overlay reports HOME CENTER / HC OFFLINE while control remains enabled, the overlay must expose a dedicated visible accessible RESTART HC or TURN HC ON affordance. STOP/Enable control is not equivalent.

Acceptance requires all of:
1. Source implementation in the real Android overlay.
2. Recovery action wired to the existing authorized Home Center/Phone Hands recovery path, not a new bypass.
3. Offline+enabled visibility rule.
4. Accessible content description.
5. Local canary/contract test.
6. APK build/install through the established deployment lane.
7. Physical-phone evidence that tapping the button attempts recovery and the overlay truthfully reports success/failure.

Until item 7 exists, the button is OWED.

## Joy acceptance
A work environment that is functionally correct but tedious, opaque, hostile, or sterile fails. Joy should arise from interaction design, responsiveness, characterful feedback, meaningful surprise, callbacks, animation/sound where useful, and the satisfaction of visible progress. Removing joy should measurably degrade the environment; removing the joke must never remove safety or truth.
