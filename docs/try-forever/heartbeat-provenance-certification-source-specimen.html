Touch a provenance state

Existing owner source is wired. A certified repository stays on the same clean HEAD and the generated-index whole-artifact SHA matches its retained inspection SHA. Repository-skill authority and prior VERIFIED_CURRENT may survive emission. This is source logic, not executed runtime proof.

Artifact A → B with repository custody still stable. Repository-skill authority may survive independently, but generated-index positive currentness becomes UNRESOLVED. A stable Git HEAD cannot certify a separately mutable external artifact.

Late repository authority is preservation-only. Changed/missing HEAD, unknown cleanliness, or a dirty late observation zeroes emitted repository-skill authority and withholds prior generated-index currentness. Matching text cannot manufacture missing prior authority.

No needless artifact re-read. Prior STALE or UNRESOLVED cannot become current through late gates, so the owner skips extra generated-index custody I/O and preserves the negative diagnostic.

Schema v4 source is wired for these fields. Repository root displays as .; an in-repository generated index displays as a bounded relative path; an external generated index displays only <external-path>. Exact internal Paths still own I/O and custody.

Regnet wound preserved. skills[*].path and discoveryErrors[*].path/related_path remain their existing repository-relative strings and do not yet pass through the collision-safe report-path projection. Do not call portable-report-path owner wiring complete.

Source, not test evidence. Owner-v4 fixtures pin inspection SHA retention, stable and changed artifact custody, late repository authority loss, strict failure, negative-state I/O suppression, and portable root/index paths. No authorized runner result has promoted them to TESTED.

Observation is not universal handle binding. Path/descriptor and late-observation gates detect persistent changes but do not prove away every swap-and-restore, identity reuse, or mutation after the final observation.
