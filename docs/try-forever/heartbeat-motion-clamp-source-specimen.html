Contract

Visible contact is semantic identity. Motion is ephemeral. Exact retry may reuse a pulse identity without blinking. Same pulse identity with different contact semantics fails closed. A schema/state token containing a decoded control character or unpaired surrogate is rejected before normalization. A persisted heartbeat whose decoded UTF-8 byte count or SHA-256 disagrees with its stored identity is rejected before semantic parsing. The current updatedMs comes from wall-clock time, so only positive presence is trusted: lower or equal absolute time is not independently a rollback/collision wound. Content identity comes from exact bytes + SHA. None of the actual wounds replaces the last-good frame or earns motion.
