## Required SPA

Each V2 example is a self-contained single-page application with exactly three primary tabs, in this exact order:

1. `ASCII`
2. `JSON`
3. `VIDEO`

### ASCII tab

- Contains the actual complete contact sheet as literal text.
- Must be selectable and copyable.
- Must use a real text/preformatted DOM surface.
- Must disable font ligatures and preserve whitespace.
- Must remain character-aligned at all supported widths; horizontal scrolling is allowed.
- Must not be an image, screenshot, canvas-only rendering, SVG outline, or bitmap substitute.

### JSON tab

Contains the reconstruction/audit payload. At minimum:

- experiment/schema/version;
- source identity and source URL;
- rights/provenance note;
- whole-sheet evidence boundary;
- OBSERVED / INFERRED / UNKNOWN split;
- abstract rig/joint schema;
- decisive key records;
- timing class and timing provenance per decisive key;
- causal role, support/contact, root/motion-arc note;
- Motion Dungeon compile parameters;
- media hash/identity;
- compatibility metadata;
- correction hooks;
- manifest/receipt facts.

This tab is mandatory even when Drew never wants to read it.

### VIDEO tab

- Contains actual compiled motion media.
- MP4 is the default required output.
- It is generated from the abstract ASCII rig + structured timing only.
- No source sprite pixels, palette, contours, traced frames, or copied layout may enter the video.
- The video must be packaged so the SPA opens without network access.
- Static art, a contact sheet, a note saying `GIF omitted`, or research prose does not satisfy this tab.

## Motion Dungeon compile law

Use the Motion Dungeon production method rather than generic tween soup:

`AUTHORED ASCII KEYS -> EXPLICIT HOLDS/TIMING -> DETERMINISTIC CONNECTIVE MOTION -> ASCII-ONLY FRAME RENDER -> MP4 -> SELF-CONTAINED SPA`

Hard rules:

- Authored decisive keys are semantic authority.
- Holds must be visibly established.
- Transitions connect keys; they may not invent a contact, support state, root decision, weapon relation, or causal event.
- Unsupported states fail closed.
- The final video may interpolate geometry only inside the already-authored abstract rig semantics.
- Motion media and SPA record hashes sufficient for deterministic readback.

## Timing law

Every decisive key has both `timing_class` and `timing_provenance`.

- `OBSERVED` only when source evidence actually establishes timing.
- Otherwise `INFERRED`.
- `ONES` = new key/drawing each display frame.
- `TWOS` = one key/drawing held two display frames.
- `FOURS` = one key/drawing held four display frames.
- `1s/2s/4s` always normalizes to `ONES/TWOS/FOURS`, never seconds.
- `STREET_FIGHTER/CAPCOM` is the nonuniform authored timing policy; it is not a claim about source-authentic duration.
