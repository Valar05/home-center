## Timing law

Every decisive key has `timing_class` and `timing_provenance`.

- `OBSERVED` only when source evidence actually establishes timing/exposure.
- Otherwise `INFERRED`.
- `ONES` = new drawing/key sample every display frame.
- `TWOS` = one drawing/key held two display frames.
- `FOURS` = one drawing/key held four display frames.
- At nominal 24 fps: ONES≈24 samples/s, TWOS≈12, FOURS≈6.
- User shorthand `1s/2s/4s` always normalizes to ONES/TWOS/FOURS, never seconds.
- `STREET_FIGHTER/CAPCOM` is nonuniform authored gameplay timing; it is never a claim of source-authentic duration.

Minimum decisive-key data:

`{key_id, pose_rig, support_contact, motion_arc_root_note, timing_class, timing_provenance, causal_role}`
