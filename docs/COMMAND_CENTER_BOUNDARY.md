# She-Raw And Command Center Boundary

Command Center is the execution and dispatch layer. She-Raw is a consultative judgment service.

Before execution, She-Raw may challenge the job.

During execution, She-Raw remains silent unless explicitly called or asked for a requested critique checkpoint.

After execution, She-Raw may critique results and identify corpus candidates.

The silence rule is enforced in code and tested by `tools/she_raw_contract_test.mjs`.

## Organ Not Worker

She-Raw is an invoked cognitive organ. Command Center jobs are bodies that execute work. Do not turn an organ invocation into a body unless the user explicitly asks for execution.

If a prior She-Raw-related job was created from this category error, cancel it and preserve the correction as She-Raw learning rather than continuing the mistaken execution premise.
