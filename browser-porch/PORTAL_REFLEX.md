# Portal Reflex became Porchlight

The original Portal Reflex planner was correctly rejected as a runtime stub. The replacement lives in [`product/`](./product/README.md).

Porchlight's product is a continuously refreshed Internet Access Map. Its local deterministic paired-tab runtime is a discovery and verification worker for that map. Workers graduate reusable site knowledge only after repeated verified success, privacy-scrub it, and can open one reviewable GitHub PR per site pack.

The old fixed parser remains useful as a small planning kernel and compatibility fixture, but it is not described as the runtime, product, deployment, or proof of portal access.

See `product/README.md` for architecture, installation, contribution modes, privacy boundaries, freshness policy, and the Lincoln receipt-truth fixture.
