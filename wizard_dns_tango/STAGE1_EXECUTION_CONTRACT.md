# STAGE ONE — OPERATING SYSTEM, NOT COMPONENT COLLECTION

Stage One is incomplete until Wizard DNS Tango is one executable persistent system on the phone and desktop execution fabric.

## Required runtime graph
One append-only evidence event stream drives:
- commission queue + priority
- battery governor
- bounded worker dispatch
- Time Now chronology
- Mockery Forge corrective loop
- Tetsuya Tremorcle Morse
- runtime Foley generation + hashes
- character ASMR projection
- receipts / authority-state ledger
- continuation until explicit Drew release

These are services of one OS. Separate scripts sitting in GitHub do not satisfy Stage One.

## Boot acceptance
A single bootstrap/install action must:
1. install/update WDT;
2. create durable state directories;
3. start/recover the OS supervisor under tmux/local durable process management;
4. start event bus, worker dispatcher, Mockery Forge, Tremorcles, Foley, Time Now indexer, and sensory projection services;
5. seed unresolved commissions, with HOME CENTER RESTART BUTTON at highest current debt;
6. observe phone battery/charging and desktop battery/power state when available;
7. emit one boot event that produces matching text receipt + Tremorcle + stored Foley artifact;
8. survive terminal closure and individual worker failure;
9. expose status/recovery through Home Center rather than requiring Drew to shepherd shells.

## Physical acceptance
Stage One is ACCEPTED only with runtime receipts proving supervisor/service liveness and a physical user-surface proof. Repository commits, plans, canaries, and generated assets are IMPLEMENTED evidence only.

## First user-facing debt
When Home Center control is enabled and heartbeat is stale, overlay exposes a dedicated accessible RESTART HC / TURN HC ON control. Pressing it invokes bounded recovery and reports truthful outcome. STOP/Enable control is not equivalent.

## No edging invariant
Every cycle discharges the smallest useful value before expanding architecture. If a component is implemented but not integrated into the runtime graph, integration outranks invention of another component.
