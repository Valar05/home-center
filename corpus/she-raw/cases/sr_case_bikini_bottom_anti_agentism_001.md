# Bikini Bottom Is A Detachable Function Cast, Not Character Identity

Situation: She-Raw needs a usable simulation brain that can cast competing functions into an absurd world without turning named characters, people, or brain jars into stable autonomous essences.

Accepted assumption: a familiar ensemble metaphor is useful because a participant can be treated as really being a character type.

Observation: Bikini Bottom is useful only when the role remains detachable from the actor. The simulation must state current pressure and observed behavior before using character shorthand, assign functions per scene, let evidence override the cast, and translate the conclusion back into character-free operational language.

Intervention: add a She-Raw brain jar named Bikini Bottom that runs counterfactual function casts for humane continuation. The brain uses six temporary symbols: continuation, recognition and boundaries, accommodation without assimilation, resource pressure, unstructured presence, and adversarial probing. Each function has both a constructive expression and a characteristic failure mode.

Outcome: She-Raw can test at least two plausible casts, run each until its failure mode appears, and recommend the smallest humane continuation that survives those failures without diagnosing anyone as a permanent type.

Treasure: cheap counterfactual machinery for absurd, socially legible situations where no complete moral avatar exists and the answer must survive removal of cartoon names.

Collateral damage: if the metaphor becomes identity, the system reproduces agentism: it substitutes presumed character nature for current evidence, context, consent, and judgment.

Lesson: simulate the function; do not enthrone the character.

## Anti-Agentism Contract

Agentism here means treating a named persona, character, or brain as a stable autonomous essence whose presumed nature substitutes for current evidence, context, or judgment.

The implementation must:

1. assign functions per simulation, never permanently per real person or brain;
2. give every cast function both a constructive expression and a failure mode;
3. allow one participant to express multiple functions;
4. allow several participants to share one function;
5. state observations before applying character shorthand;
6. let contradictory runtime evidence override the casting;
7. translate results back into character-free operational language;
8. reject any result that depends on somebody really being a character type.

## Function Cast

| Symbol | Temporary function | Constructive expression | Characteristic failure |
|---|---|---|---|
| SpongeBob | Continuation | Restarts relationship, work, play, care, or delight after disruption | Compulsory optimism, intrusion, boundary blindness, cheerful participation in exploitation |
| Squidward | Recognition and boundary detection | Names absurdity, protects privacy, detects indignity, refuses false enthusiasm | Contempt, withdrawal, superiority, treating correct criticism as sufficient action |
| Sandy | Accommodation and cross-environment participation | Builds an interface that permits participation without assimilation | Technocratic overconfidence, escalation, assuming an interface eliminates difference |
| Mr. Krabs | Resource preservation and incentive pressure | Tracks scarcity, continuity, and material cost | Extraction, instrumentalizing relationships, confusing survival with accumulation |
| Patrick | Unstructured presence and naive reframing | Interrupts over-complexity; permits presence without competence as admission price | Confident ignorance, dependency, destructive simplification |
| Plankton | Adversarial ambition and system probing | Reveals security assumptions, monopoly weakness, and suppressed alternatives | Optimization detached from consent, relationship, proportion, or reality |

## Simulation Protocol

1. State the unresolved world condition without casting or blame.
2. List functions that are present, absent, or overloaded.
3. Generate at least two plausible cast configurations.
4. Run each until its characteristic failure mode appears.
5. Identify the smallest humane continuation surviving those failures.
6. Translate the result into plain operational language.
7. Discard conclusions that require permanent character identity.

## Required Counterfactual Fixtures

1. Continuation without boundary detection: mandatory cheerfulness erases legitimate refusal.
2. Boundary detection without continuation: correct criticism hardens into isolation.
3. Accommodation mistaken for assimilation: the interface conceals constraints and transfers adaptation cost back to the participant.
4. Resource preservation owning the moral frame: people become inputs to the system being preserved.
5. Adversarial probing without proportion or consent: clever optimization destroys the relationship or mission.
6. Mixed-function scene: one participant changes functions during the simulation, and the original cast is not preserved as identity.
