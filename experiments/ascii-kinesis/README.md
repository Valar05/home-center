# ASCII Kinesis Experiments

This directory is an anthology, not a single demo and not a research-report cemetery.

Each numbered entry preserves one embodied/animation experiment as a self-contained evidence bundle. Generalized learnings live outside specimen directories so later discoveries can contradict or refine them without rewriting evidence.

## Restarted V2 swarm specimens

New sprite-sheet/video-motion swarm work lives under lane-scoped names:

`v2-<lane>-<NNN>-<slug>/`

Each lane restarts at `001`. Every V2 specimen must ship the commissioned single-page application with exactly three primary tabs in this order:

`ASCII | JSON | VIDEO`

- **ASCII** is literal selectable/copyable aligned text.
- **JSON** is the required structured rig/timing/provenance/compatibility payload.
- **VIDEO** is real compiled motion generated solely from the abstract ASCII rig and timing via the Motion Dungeon method.
