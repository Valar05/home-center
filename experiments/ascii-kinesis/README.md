# ASCII Kinesis Experiments

This directory is an anthology, not a single demo.

Each numbered entry preserves one embodied/animation experiment as a self-contained evidence bundle. Generalized learnings live outside the specimen directories so later discoveries can contradict or refine them without rewriting evidence.

Current entries:

- `001-backward-stairs` — backward stair descent / ascent and the diagonal hip-shift discovery.

See `docs/ASCII_KINESIS_ANTHOLOGY.md` for the bundle and compatibility contract.
