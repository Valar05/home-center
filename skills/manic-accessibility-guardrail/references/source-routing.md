Keep these states separate:

- requested evidence lane;
- retrieved evidence lane;
- mirror/cache fallback;
- current native source;
- repository doctrine;
- runtime/deployment evidence.

Never report a Library mirror, repository copy, or remembered route as Home Center Drive readback.
