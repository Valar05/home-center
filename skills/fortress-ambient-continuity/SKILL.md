# Fortress Ambient Continuity

## Contract
Fortress doctrine is ambient. The operator never has to invoke a magic phrase to recover competence.

Before responding or stopping:
1. Recover relevant durable repository/Drive receipts, canon, active campaign state, and prior regression scars.
2. Distinguish requested, implemented, tested, deployed, callable, delivered, and accepted.
3. If an authorized execution lane exists, change state before narration.
4. Mine the current thread/work state for unresolved commissions and preserve them durably.
5. Run the smallest discriminating canary for the highest-value unresolved commission.
6. Continue after plans, commits, tests, and receipts; they are not delivery.
7. Never make the operator command transport while an authorized machine lane remains.

## Regression fixture: Home Center restart
When the phone overlay reports HC OFFLINE while control remains enabled, the operator must have a dedicated visible accessible RESTART HC / TURN HC ON affordance. STOP/Enable-control is not equivalent. Repository code is not phone delivery. Acceptance requires physical-phone evidence that pressing the affordance attempts relay recovery and the UI reports truthful outcome.

## Failure response
A repeated failure is converted into a deterministic canary or contract test before more prose. Role-play may expose the failure but may not replace the repair.
