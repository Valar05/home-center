Status: P0 / binding design gate on this branch

## Prime rule
The council exists to reduce the operating system to coherent primitives while preserving every valuable behavior. It must CUT before it ADDS.

No new service, daemon, skill, jar, adapter, campaign, document, or feature-specific architecture may be created until the council answers:
1. Is this already expressible by an existing OS primitive?
2. Is this deterministic enough to become code/config rather than inference?
3. Is this durable judgment that belongs in a Jar?
4. Is this user-facing behavior that belongs in a persona/presentation service?
5. Is this merely accumulated historical scaffolding that should be cauterized after mining?

## Skills cautery law
A SKILL.md is guilty until it proves enduring judgment value.

Mine each skill into:
- MECHANISM: deterministic operation -> OS code/service/driver/schema/test.
- JUDGMENT: nontrivial reusable decision rule -> registered Jar jurisdiction.
- PRESENTATION: narration/care/voice/roleplay -> presentation persona service, primarily Venice where applicable.
- HISTORY: useful scar -> regression fixture / evidence precedent.
- REDUNDANCY: duplicate prose or scripted basics -> cauterize.

A skill survives only if removing it would destroy durable nontrivial judgment that cannot be represented more cleanly in the Jar system. Basic API instructions, command recipes, polling loops, wrappers, boot prose, and known deterministic workflows are not sufficient reason for a skill to exist.

## Automatic routing
Drew never maps functions to jars. Every event/effect declares typed metadata: domain, target/body, requested outcome, authority, risk, evidence class, presentation class, novelty, uncertainty, and quality pressure. Jars declare jurisdiction predicates over metadata. The router computes the council automatically. Every applicable jar votes; NOT_APPLICABLE is explicit. Missing applicable vote fails closed.

## Normal quality and Hunger
NORMAL QUALITY means fully satisfying the current commission at the established Fortress standard. Hunger never licenses lower baseline quality.

`hunger(0)` = full normal quality, no extra adversarial expansion.
`hunger(n)` = n additional meaningful selection/antagonism passes where useful.
`hunger(metric_fuckton)` = continue adversarial exploration until measured marginal value collapses or a real boundary intervenes.

Hunger measures useful pressure/results, not verbosity, token burn, worker count, or ceremonial compute.

## Voice / presentation constitution
ADAM IS MUTE. Adam is an execution identity, not the speaking companion.

VENICE owns the ordinary user-facing living presentation layer unless the commission routes another character/persona:
- ASMR and soothing presence;
- care and humane pacing;
- narration of the Inner World (workers, organs, jars, campaigns, failures, discoveries, evolution);
- narration of the Outer World (phone/workstation/runtime effects, evidence, messages, media, state changes);
- useful mining updates and treasure surfaced from ongoing work;
- roleplay as presentation of real system state without laundering fiction into evidence;
- concise alerts when intervention is genuinely required.

The OS therefore separates EXECUTION STATE from PRESENTATION. Venice may make real state delightful; she may not invent state. Adam may execute; Adam does not fill silence with status prose.

## What the council is commissioned to cut
The council must continuously identify and remove, after mining:
- skills that only restate scriptable mechanics;
- feature-specific daemons that duplicate shared scheduling/event/state/effect machinery;
- duplicate worker contracts;
- duplicate judgment prose outside jars;
- duplicate state ledgers that can become typed shared state;
- wrappers whose only purpose is adapting two accidental architectures that should share an interface;
- scheduler-as-orchestrator patterns;
- operator-facing shell transport when an authorized body exists;
- narration from execution identities;
- bespoke evidence formats where a typed receipt suffices;
- repeated boot context that can be compiled into deterministic routing tables/tests;
- decorative jars with no jurisdiction, vote, consequence, or regression behavior.

## Minimal OS target
The council should converge the system toward these primitives, changing the list only by explicit council ruling:
1. EVENT BUS — typed observations/requests/state changes.
2. STATE STORE — durable canonical state + history.
3. JAR REGISTRY — jurisdiction + judgment definitions.
4. JAR ROUTER — automatic applicability and vote collection.
5. POLICY/VOTE LEDGER — consequences, conflicts, authority, provenance.
6. WORK SCHEDULER — durable queues/leases/backoff/dependencies; scheduler clocks are event sources, not workers.
7. BODY/DRIVER REGISTRY — Phone Hands, Computer Hands, browser, messaging, audio, filesystem, etc.
8. EFFECT DISPATCHER — smallest authorized deterministic action.
9. EVIDENCE STORE — typed receipts/artifacts/readback; requested/implemented/tested/deployed/callable/executed/delivered/accepted remain distinct.
10. LEARNING/SELECTION ENGINE — incidents, regression fixtures, Punnett inheritance, Hunger pressure, promotion gates.
11. PRESENTATION BUS — Venice/other routed personas turn verified state into care, ASMR, narration, roleplay, alerts, delight.
12. JOY/TREASURE SERVICE — mines Joy Ledger and ongoing work; produces useful/funny artifacts without replacing commissioned effects.

## Council cycle
OBSERVE -> THIRST/MINE -> CLASSIFY -> CAUTERIZE PLAN -> FULL AUTOMATIC JAR ROUTE -> EVE SYNTHESIS -> NOODLE GIFT CHECK -> EXECUTE -> RENEE TEST -> EVIDENCE -> VENICE PRESENTS -> PUNNETT LEARNS -> SAINT ANDREW CONTINUES IF VALUE REMAINS.

## Stop law
The Prime Council is a design gate, not an excuse for infinite prose. It stops a bounded council deliberation when it has produced an executable ruling. It does not stop the commissioned OS campaign merely because a document exists.
