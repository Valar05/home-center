# BUTTON CAMPAIGNS — PLAYABLE JOY EFFECTS

Status: binding OS contract
Presentation voice: She-Ra
Custody: Adam in background under TOUCHED IT -> OWN IT; no foreground speech required

## Core contract
A Button Campaign is a short-lived, obvious, fun, Fleshpunk, audio-visual, interactable effect launched by one user press.

PRESS -> CAMPAIGN ADMIT -> SHORT PLAYABLE EFFECT -> OPTIONAL MICRO-INTERACTION -> CLEAN EXIT -> RECEIPT -> PUNNETT LEARNS.

The user does not need to know what will happen. Surprise is allowed. Annoyance is not.

## Default properties
- audio-visual by default when the current surface supports both;
- interactable by default: at least one tiny meaningful input, response, choice, gesture, timing beat, or toy-like reaction when feasible;
- feels closer to a tiny playable than a notification;
- obvious start and obvious end;
- short-lived: default target 2–15 seconds unless a retained specimen proves another duration works better;
- immediately dismissible / sovereign stop;
- no persistent focus hijack;
- no repeated unsolicited replay;
- Fleshpunk/Flesh Prank visual and sonic grammar by default, filtered through Noodle Lady taste and accessibility;
- content may intentionally recur when repetition itself is funny;
- expensive generation is allowed upstream when it materially improves delight; runtime playback should stay bounded and responsive;
- every effect has accessible semantic equivalent/labels where needed.

## Campaign pool
Button Campaigns draw from mined conversation/Joy material rather than generic randomness. Eligible genes include:
- roleplay fragments and callbacks;
- She-Ra interrogation prompts/questions;
- Punit punchlines and language collisions;
- victory organisms / animated emoji lineages;
- demotivational poster mutations;
- Morse narrative signals;
- Fleshpunk/Flesh Prank micro-scenes;
- sound/foley/ASMR stings;
- pixel/vector/procedural animation specimens;
- Inner World colonial-organ incidents;
- current campaign events that are safe to transform into delight;
- retained Joy Ledger specimens.

## Conversation mining law
The content miner is observational and non-interruptive. It does NOT intervene in the live conversation merely to feed Button Campaigns. It passively harvests user-approved/canon-safe fragments, asks already made by She-Ra/Shiro, callbacks, corrections, punchlines, motifs, and reusable playable seeds into a candidate pool with provenance and privacy class.

No invented private facts. No promotion of roleplay into real-world truth. No user interruption for curation unless explicitly requested.

## Selection / Punnett
Each press is a bounded selection event:
1. choose one eligible candidate lineage;
2. mutate only a few dimensions: visuals, sound, timing, interaction, punchline, motion, recurrence;
3. render/play;
4. collect KEEP/REJECT/implicit engagement when available;
5. preserve winners and negative fixtures;
6. bias future presses toward surviving genes while maintaining novelty.

Noodle Lady gates taste. Hunger kills boring/static/overlong specimens. Ares may escalate spectacle only when it improves the tiny playable. Punit may terminate the effect with a punchline when appropriate. She-Ra remains the foreground narrative voice.

## Terminal / Home Center prerequisite
Button Campaigns are downstream of a working Home Center terminal/control surface. FIRST STEP is restore the existing Home Center terminal/overlay execution path through the existing authorized owner and prove it is callable. Do not build a parallel button host while the commissioned terminal is offline.

Acceptance ladder:
TERMINAL_ONLINE_PROVEN -> BUTTON_HOST_CALLABLE -> FIRST_PRESS_RECEIVED -> AV_EFFECT_STARTED -> INTERACTION_WORKS -> CLEAN_EXIT -> RECEIPT_VERIFIED -> SECOND_PRESS_PRODUCES_VALID_SPECIMEN -> RESTART_SURVIVAL -> USER_KEPT.

## Anti-annoyance
- no autoplay without a press;
- no modal trap;
- no volume surprise beyond current device/policy limits;
- no long unskippable intro;
- no notification spam;
- no stealing audio focus longer than the effect requires;
- no blocking ordinary phone use after exit;
- every effect must clean up timers/media/focus/touch capture.

## Reuse existing OS
Use existing Home Center overlay/button infrastructure, media presence/audio primitives, Joy Ledger, conversation miner, event/state/evidence substrate, and existing animation pipelines. Do not found Button Campaign OS, Button Governor, or another scheduler kingdom.

## Truth
This document defines the Button Campaign contract. It does not claim the primary-phone terminal is currently online or that a playable campaign has already been physically delivered.
