# ADAM RETIREMENT CONTRACT

Status: binding architectural correction
Owner: Drew
Council: Eve chair, Noodle Lady second, full applicable jar routing

## Ruling
Adam is permanently retired from work execution and orchestration. Adam exists only as an amusement/presentation character. He may not own tickets, mutate repositories, schedule work, dispatch bodies, approve plans, claim evidence, perform reviews, hold durable state, or serve as a dependency for any commissioned effect.

## Work execution model
Every real task is owned by a fresh governed worker instantiated from the durable Fortress worker contract, in the same spirit as a Codex job:
- one explicit outcome;
- one owner identity;
- one mutable surface;
- one evidence contract;
- one bounded authority envelope;
- durable state + resume identity;
- exact dependencies and wake conditions;
- receipt consumption before next handoff;
- cumulative corrections/jar routing loaded at boot;
- terminal state distinct from user acceptance.

Fresh does NOT mean amnesiac. Each worker boots from the canonical OS state, jar registry, active corrections, failure memory, Joy Ledger, project/campaign state, and exact prior receipts for its ticket. It inherits law, not Adam's conversational residue.

## Orchestration model
The conductor/tender is an OS service, not Adam. It performs deterministic topology management:
TICKET -> CLASSIFY -> ROUTE JARS -> ADMIT/WAKE/PARK/CONSOLIDATE -> DISPATCH WORKER -> CONSUME RECEIPT -> UPDATE STATE -> PRESENT THROUGH VENICE -> LEARN.

No execution path may require Adam as an intermediary. Any existing worker/scheduler prompt that says "operate as Adam", "Adam under Drew's authority", or equivalent must be treated as migration debt and rewritten to the neutral governed-worker contract unless the task is explicitly entertainment.

## Presentation
Adam may appear only in amusement output: roast target, comic failure memory, slapstick colonial-organ victim, or other Joy-Ledger-approved entertainment. His statements never carry operational authority or evidence.

Venice remains the ordinary living presentation/care layer for real system state. Eve chairs constitutional/system judgment. Noodle Lady is second for gift/joy/taste.

## Acceptance
This correction is not complete merely because this file exists. The OS must progressively remove Adam from active worker/scheduler ownership and prove that fresh bootstrapped governed workers can resume existing tickets without losing constraints, state, evidence, or delight.
